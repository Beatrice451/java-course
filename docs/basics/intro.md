# Введение в Java

Java - это строго типизированный, объектно-ориентированный язык программирования общего назначения. Разработан Джеймсом Гослингом в Sun Microsystems и выпущен в 1995 году. Сегодня поддерживается Oracle и сообществом OpenJDK.
Изначально язык назывался Oak, в честь дуба, который рос за окном Гослинга. Но оказалось, что название занято, поэтому язык был переименован в **Java** - в честь сорта кофе, который пили разработчики. Логотипом стала чашка с дымящимся кофе.

## Почему Java

- **Кроссплатформенность** - принцип «Write Once, Run Anywhere». Скомпилированный байт-код выполняется на любой ОС через JVM
- **Строгая типизация** - ошибки типов ловятся на этапе компиляции, а не в рантайме
- **Управление памятью** - сборщик мусора избавляет от ручного освобождения памяти
- **Многопоточность** - встроенная поддержка конкурентности на уровне языка
- **Экосистема** - Spring, Jakarta EE, Android, Big Data, микросервисы

## Экосистема: три ключевых компонента

### **JVM (Java Virtual Machine) — Виртуальная машина Java**

**Что это:** Абстрактная вычислительная машина, которая выполняет Java-байткод.

**Ключевые моменты:**

- Интерпретирует или компилирует байткод в машинный код конкретной платформы
- Обеспечивает принцип "Write Once, Run Anywhere" (написал один раз — запускай везде)
- Управляет памятью (garbage collection), безопасностью и многопоточностью
- Зависит от операционной системы (разные JVM для Windows, Linux, macOS)

Сердце Java. Именно JVM позволила джаве стать одним из самых распространенных языков программирования. Неважно на чём вы запускаете код. Если для этой платформы есть реализация JVM - код запустится. Хоть на холодильнике.

___

### **JRE (Java Runtime Environment) — Среда выполнения Java**

**Что это:** Набор программных компонентов для запуска Java-приложений.

**Состав:**

- **JVM** + стандартные библиотеки Java (java.lang, java.util и др.)
- Вспомогательные файлы и ресурсы

Предназначена для пользователей, которым нужно только **запускать** Java-приложения.
Хотите запустить майнкрафт? Вам нужна JRE.

___

### **JDK (Java Development Kit) — Набор разработчика Java**

**Что это:** Полноценный инструментарий для разработки Java-приложений.

**Состав:**

- **JRE** (всё, что есть в JRE)
- **Компилятор javac**
- **Отладчик jdb**
- **Документатор javadoc**
- **Архиватор jar**
- Другие инструменты разработки

Хотите написать майнкрафт 2? Вам нужна JDK.
___

Кратенькая таблица:

| Компонент                          | Назначение                                    | Нужно для               |
| ---------------------------------- | --------------------------------------------- | ----------------------- |
| **JVM** (Java Virtual Machine)     | Исполняет байт-код, абстрагирует от ОС        | Всего                   |
| **JRE** (Java Runtime Environment) | JVM + стандартные библиотеки                  | Запуска программ        |
| **JDK** (Java Development Kit)     | JRE + компилятор (`javac`), отладчик, утилиты | **Разработки** программ |


:::warning Что из этого нужно-то?
Если вдруг кто-то не понял - для разработки используется **JDK**!
:::

## Как работает компиляция (в двух словах)

Java - **двухэтапный** язык:
1. **Компиляция**: `javac` переводит исходный код в **байт-код** (`.class` файлы). Байт-код платформонезависим
2. **Выполнение**: `java` запускает JVM, которая интерпретирует или JIT-компилирует байт-код в нативный код конкретной платформы

> Исходник (.java) -> `javac` (компилятор) -> Байт-код (.class) -> `java` -> JVM -> Машинный код  

## Первая программа
### Hello World
Создайте файл `HelloWorld.java` и откройте его в любом текстовом редакторе (можно блокнот). Вставьте туда следующий код:

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

:::warning Важно!
Название файла и имя класса (`public class *имя класса*` в первой строке) должны точно совпадать! Если файл назван `HelloWorld.java`, а класс `WorldHello` (`public class WorldHello`), то при компиляции возникнет ошибка.
:::

Пока что нас интересует одна строка:

```java
System.out.println("Hello, World!");
```

Она выводит переданный текст в консоль.

### Компиляция и запуск

Сначала код необходимо скомпилировать, используя `javac`. После этого рядом с `HelloWorld.java` появится `HelloWorld.class`. Теперь с помощью `java` его можно запустить. Пример:
```bash
javac HelloWorld.java # компиляция в байт-код
java HelloWorld # запуск
```

:::warning Запуск после компиляции
Обратите внимание на вторую команду. В ней мы указываем не название файла (не `HelloWorld.java` и не `HelloWorld.class`), а название **класса!** То есть `HelloWorld`!
:::

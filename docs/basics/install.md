# Установка всякого

Для разработки на Java необходимы:
1. JDK ([что это?](intro.md#jdk-java-development-kit-—-набор-разработчика-java))
2. IDE или любой текстовый редактор

## Установка JDK

Для разработки нужна **JDK** (Java Development Kit), а не JRE.

::: warning Версия
Используйте **LTS-версии**: 21 или 25. Нечётные версии (22, 23, 24) - короткого цикла поддержки и не рекомендуются для продакшена (но мы не продакшн делаем, верно? Качайте на своё усмотрение, но учтите, что курс создан под 25 версию).
:::

Для совсем ленивых:
https://www.oracle.com/java/technologies/downloads/#java25

### Проверка установки

```bash
java --version
javac --version
```

Первая команда должна вывести что-то вроде:
```bash
java 22.0.1 2024-04-16
Java(TM) SE Runtime Environment (build 22.0.1+8-16)
Java HotSpot(TM) 64-Bit Server VM (build 22.0.1+8-16, mixed mode, sharing)
```

Вторая:
```bash
javac 22.0.1
```

## А где буквы писать? (IDE)

Очевидно, код в блокноте мы писать не будем. Так что тут два варианта...

### У вас есть ноутбук

Если так, то замечательно. Что можно скачать:

#### IntelliJ IDEA
В идеале скачать `IntelliJ IDEA`. Это полноценная IDE с автодополнением, подсветкой ошибок, встроенным терминалом, интеграцией со сборщиками, отладчиком и прочими классными штуками. Есть две версии:
1. `Community Edition` - бесплатна, но функционал несколько урезан. Для данной дисциплины хватит с головой;
2. `Ultimate Edition` - требует подписки (но если сильно хочется, то бесплатно). Полный функционал. Для данной дисциплины, скорее всего, избыточно, так что на ваше усмотрение.  

Но! Intellij довольно требовательна к системе, поэтому, если у вас древний ноутбук, то лучше рассмотреть VS Code.

::: tip 
Именно IntelliJ IDEA я буду использовать на парах. Хотите максимальной повторяемости - качайте именно её.
:::

#### Visual Studio Code
Visual Studio Code - текстовый редактор (очень крутой текстовый редактор). Не имеет средств для разработки на Java "из коробки". Но имеет поддержку огромного количества плагинов, что делает его безумно гибким. Накатили пару плагинов - получили почти IDE. Полностью бесплатный, легковесный. Потянет даже на калькуляторе.

#### Ваш вариант

Мне без разницы в чём вы пишете код. Хоть в блокноте. До тех пор, пока код работает.
